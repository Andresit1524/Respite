> Hecho con C# + WPF.

Una aplicación para descansar del PC un rato. Pomodoro + límites configurables.

## ¿Cómo funciona? 
Además del Pomodoro de toda la vida (con configuraciones y personalización), el sistema te avisa cada dos horas (desde que prendes el PC, es automático) para que descanses 10 minutos, y te minimiza todas las ventanas para garantizarlo.

Puedes configurar sesiones más largas sin interrupciones, pero estas jornadas no pueden ser más extensas que 6 horas. El pomodoro pausa estos límites duros. También puedes configurarlos para que duren otro tiempo diferente.
